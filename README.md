# YouTube Auto-Dub & 100-Language Subtitles (Manifest V3) - v1.3.0

## Key Updates:
1. **Two-Stage Audio Ducking**:
   - Drops video volume to **5%** when line begins.
   - **FULLY MUTES (0%)** the original video while dubbed speech is playing.
   - Smoothly restores original volume when the line ends.
2. **Anti-Repetition Guard**:
   - Completely prevents repeated phrases or looped speech.
3. **Zero-Delay Playback Engine**:
   - 250ms anticipatory pre-buffering with strict boundary enforcement.

---

## How to Install in Chrome / Edge / Brave:
1. Download `youtube-auto-dub-extension.zip`.
2. Extract the folder.
3. Go to `chrome://extensions`.
4. Enable **Developer mode** toggle in top-right.
5. Click **Load unpacked** and select the folder.
